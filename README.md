## Projects

### [Lantern](https://github.com/haiduh/lantern) — Homelab System Monitor
Self-hosted desktop dashboard for monitoring CPU, memory and processes across multiple machines from a single UI. Electron/React/TypeScript frontend polling a lightweight FastAPI agent per machine — reads directly from `/proc`, no external dependencies.

### [kb-mcp-server](https://github.com/haiduh/kb-mcp-server) — Knowledge Base MCP Server
Local MCP server that gives Claude Desktop structured access to a personal markdown knowledge base. Exposes search, read and write tools. Semantic search via sentence-transformers and ChromaDB — queries match on meaning, not keywords. Cross-platform via pathlib.

### [proc-monitor](https://github.com/haiduh/proc-monitor) — Linux Process Monitor
Zero-dependency Linux CLI that reads directly from `/proc` and outputs real-time CPU and memory stats. Built for homelab use.

### AI Game Assistant — Final Year Project
Real-time RAG-powered in-game assistant with an Electron/React overlay and modular dataset uploads. Context-aware guidance using retrieval-augmented generation.
